# Паранормальный бар: тело от 1,6 ATR

Последняя поправка пользователя от 25 сентября 2026 заменяет порог 2,5 ATR:

**`abs(Close − Open) >= 1.6 × ATR`**.

Ровно 1,6 ATR подходит. Учитывается тело без хвостов. ATR считается прежним
способом по 14 предыдущим True Range, без включения текущего бара.
Единый порог применяется в поиске уровней, структурных подтверждениях,
контексте подхода, детекторе ложного пробоя и обоих SCN-002 бэктестах.
Параметры движения и разворота для излома тренда не менялись.

- 1 июля 2026: тело 1 396,5 / ATR 2 220,0643 = **0,629 ATR** — не паранормальный.
  Относительно 58 042,6 остаётся ложным пробоем; прежний БСУ 25 июня сохраняется.
- 22 апреля 2025: тело 5 928,9 / ATR 3 270,6357 = **1,813 ATR** — теперь
  соответствует порогу. Основание проверяется по телу, а не по полному размаху.

Запрет уровней ГЭПа, проторговки и уровня от ЛП сохраняется. ЛП остаётся
контекстом входа. Ручные линии, комментарии и режим просмотра кандидатов ±1%
не изменялись. Старые численные отчёты остаются историческими; новое среднее
отклонение цен здесь не рассчитывалось.

Проверки охватывают точную границу 1,6, значения ниже неё, оба направления
свечи, длинные хвосты при малом теле, общую классификацию во всех путях и
исторические случаи 1 июля и 22 апреля. Итог полного запуска — в
[active_methodology.json](active_methodology.json).
