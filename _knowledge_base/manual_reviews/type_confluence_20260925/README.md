# Несколько подтверждённых типов усиливают один уровень

Уточнение пользователя: одна линия может одновременно быть лимитной,
зеркальной, образованной паранормальным баром и изломом тренда.
Она учитывается один раз в количестве уровней, а сочетание типов усиливает её.

В `knowledge_bot/level_selection.py` добавлена проверка `level_type_confluence`.
Она проверяет обычные подтверждающие касания и записывает список типов,
их число и дополнительный бонус в `selection.type_confluence`.

Начальная настройка бонуса для дальнейшего ручного уточнения:

| Подтверждённых типов у одной линии | Дополнительный балл |
|---:|---:|
| 1 | 0 |
| 2 | 0,5 |
| 3 | 1,0 |
| 4 | 1,5 |

Коэффициент 0,5 выбран при реализации; пользователь не задавал его численно.
Бонус добавляется к имеющейся оценке реакции, размера тел, плотности и структуры.
Он не отменяет проверки основания, распила и минимального расстояния 1,5%.

- Лимитный тип требует повторных обычных касаний с одной стороны.
- Зеркальный — подтверждённой пары обычных касаний с разных сторон.
- Паранормальный — соответствующего основания и обычного подтверждающего
  бара с телом от 1,6 ATR.
- Излом — подтверждённого статуса и допустимого опорного бара.
- ЛП и неподтверждённые подписи не увеличивают число типов.
- `limit_level` и `two_bar_limit` — один лимитный тип; повторения тегов не дают
  дополнительных баллов. Круглое число остаётся отдельным фактором силы,
  а не пятым типом уровня.

Цена линии не изменяется. Новые дубли линий не создаются. База знаний
`botArtjahan-main` и пользовательский журнал не переписывались.

Пересчёт BTCUSDT 1d на сохранённых свечах по 23.09.2026 оставил тот же состав:
27 уникальных рабочих уровней без удалений целых линий, 20 с действующими
удалениями (20 исключений БСУ учтены в обоих случаях). Изменились баллы силы.
Например, 58 042,6 имеет два типа и бонус 0,5; 94 000 — три типа и бонус 1,0.
