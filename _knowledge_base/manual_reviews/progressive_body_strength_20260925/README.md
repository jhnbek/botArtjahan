# Плавная шкала силы тела бара

Уточнение пользователя от 25.09.2026: тело 1,35 ATR не является паранормальным,
но более крупное тело должно иметь большее влияние на силу уровня.
Правило реализовано в `knowledge_bot/level_evidence_strength.py`.

## Шкала

Размер тела `r = abs(Close - Open) / ATR14`. ATR берётся по 14 предыдущим
барам, проверяемая свеча в него не включается. Начальная формула для дальнейшей
ручной корректировки:

`вес тела = 2,5 × r / (r + 1,5)`.

Она непрерывно возрастает, при 1 ATR даёт 1 балл и плавно приближается к
2,5 балла. Так большие тела сильнее, а отдельный экстремальный бар не получает
неограниченный вес. Формула и её коэффициенты — выбранная настройка алгоритма,
а не число, которое пользователь указал или которое было обучено на примерах.

| Тело / ATR | Вес тела | Паранормальный по телу |
|---:|---:|---|
| 0,25 | 0,3571 | Нет |
| 0,50 | 0,6250 | Нет |
| 1,00 | 1,0000 | Нет |
| 1,35 | 1,1842 | Нет |
| 1,60 | 1,2903 | Да |
| 2,00 | 1,4286 | Да |
| 3,00 | 1,6667 | Да |
| 4,00 | 1,8182 | Да |

Порог **тело ≥1,6 ATR** отвечает за классификацию бара. В шкале силы на этой
границе нет скачка. Выше 2,5 ATR вес продолжает расти: прежнее жёсткое ограничение
размера больше не делает разные большие тела одинаковыми по весу.

## Как вес входит в силу уровня

- Приход цены к уровню и размер тела теперь дают отдельные компоненты.
  Прежнее `min(2.5, max(body_atr, arrival_atr))` могло полностью скрыть влияние
  тела, если приход был больше; теперь этого нет.
- Вес получают допустимые обычные опорные бары, участники плотной группы и
  опорные бары подтверждённых обычных отбоев. Участник плотной группы может
  влиять своим телом, даже когда другой бар выбран лучшим в эпизоде отбоя.
- В итог складываются два наибольших веса **разных баров**. Один бар не
  дублируется, если он одновременно БСУ, участник группы и начало отбоя.
  Величина прихода по-прежнему учитывается по независимым эпизодам.
- Для каждого бара сохраняются отношение тела к ATR, вес, основание допуска,
  момент подтверждения и признак участия в итоговой сумме.
- ЛП, включая ЛП прежней опоры, не получает этого веса. Обычный контакт на
  том же баре также не позволяет обойти исключение ЛП из оценки силы.
- Большое тело само по себе не создаёт уровень. Проверки собственной опоры,
  реакции, распила, касаний, истории за 18 месяцев и расстояния 1,5% сохранены.

## Проверка бара 29 августа 2025

На сохранённых свечах тело = **1,346725 ATR**, вес = **1,182697 балла**.
Бар участвует в плотной группе около 107 421,7 и теперь входит в два
учитываемых тела этой группы/реакций. Он остаётся обычным баром по критерию
паранормальности. Вес группы доступен после её подтверждения, а не задним
числом на 29 августа.

Это не означает автоматического выбора его Low как новой точной цены БСУ:
правила выбора цены и сохранённое удаление 107 421,7 не отменялись. Ручная линия
107 433,76 и её комментарий сохранены. Журнал графика и `botArtjahan-main`
не изменялись.
