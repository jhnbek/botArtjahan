# Новые входы по часовому ATR

Часы вычислены по авторским условиям и выбранному варианту индикатора из базы: [методика 5 / 150% / 50%](h1_atr_method.md). В расчёт ATR и признаки входят только закрытые свечи до начала указанного часа. Диапазон самого часа используется для разметки достижения порога; точное исполнение не установлено. Уровни восстановлены по синим линиям приблизительно.

№23 исключён по указанию автора. У №113 использована разрешённая исходной подписью альтернативная ATR-ветка; индивидуальный выбор автора между ней и немедленным пробоем не утверждается. Для всех новых примеров сохранено только положительное состояние, без выдуманных ожиданий.
