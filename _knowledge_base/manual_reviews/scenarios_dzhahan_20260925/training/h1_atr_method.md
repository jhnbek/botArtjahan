# Расчёт часового ATR из базы знаний

Пользователь подтвердил: для условий входа нужен средний ATR **часовых биржевых свечей**, рассчитанный по базе знаний. Выбрана воспроизводимая версия видимого индикатора Pine: **5 / 150% / 50%, фильтр включён**. Это выбранная проектная реализация, а не индивидуальное подтверждение каждого вычисленного часа автором.

Диапазон — High−Low. Для каждого бара вычисляется обычное среднее пяти диапазонов, включая этот уже закрытый бар, и проверяется диапазон 50–150% от его собственного среднего. Если предыдущий бар фильтр не прошёл, индикатор возвращает обычное среднее последних пяти. Если прошёл — берёт пять предыдущих позиций; не прошедшая позиция заменяется ближайшей более свежей прошедшей. Один диапазон может участвовать несколько раз: именно так написан видимый цикл в источнике.

Для часа потенциального входа используется результат **на последнем закрытом H1**. Значение фиксируется до следующего закрытия. Требуются десять положительных закрытых часовых диапазонов; отсутствие истории, разрыв или нулевой диапазон не превращаются в предполагаемый ATR. Полный High−Low часа входа не участвует в его ATR или признаках модели.

Триггер long: уровень + 1 ATR; short: уровень − 1 ATR. Поиск начинается не раньше фактического закрытия необходимого D1. OHLC последующего часа используется только для локализации учебного часа достижения порога; точная минута и цена исполнения не установлены. Если условие уже выполнено по закрытой цене на разрешённой границе, используется эта граница.

Источники: [код индикатора](atr_method_sources/pine_excerpt.jpg), [описание настроек](atr_method_sources/indicator_settings.md), [первичная лекция](atr_method_sources/closed_bar_transcript.md), в том числе 02:11:24.620 о включении бара после закрытия. Контрольные суммы и ограничения: [h1_atr_method.json](h1_atr_method.json).

Строка hi0=high скрыта выше кадра: её значение восстановлено по методике High−Low. Полный Pine-скрипт не получен; исполнение порта в Pine не проверено. Ручной отбор пяти сопоставимых свечей с иными порогами аномальности — отдельная методика, здесь не смешивается с индикатором. Нормализация прежних признаков и определение ПН сохраняют собственные формулы; этот модуль задаёт только новый порог авторских условий H1.
