## Как использовать в проекте

Коллекция — дополнительные ручные примеры для исправления методики и будущего
поиска входов. Самообучение, подстройка весов или торговля не запускаются.
Для каждого номера следует разбирать дневной уровень отдельно от часового
триггера. Ложный пробой служит сигналом входа, а не подтверждением силы уровня.

Рекомендуемая карточка разбора: номер сценария, обе ссылки и SHA-256, инструмент,
биржа, дата и часовой пояс, точная цена уровня, даты и типы его БСУ/подтверждений,
реакция и распил, дата/время часового входа, тип ЛП (один/два бара), отмена
сценария, комментарий пользователя. Неясные поля остаются незаполненными.
После проверки разметки и сверки свечей условия можно переносить в общие правила кода
и проверять на свечах, ограниченных датой сценария. Сами изображения с уже
известным исходом не передаются детектору как будущие данные.

В проекте уже есть заготовки:

- `knowledge_bot/ingest_scenario_archive.py` группирует именно имена
  `1D_N.jpg`/`1H_N.jpg`, выполняет OCR и пишет `scenario_index.jsonl`.
- `knowledge_bot/link_scenarios_to_market.py` связывает распознанные даты и
  тикеры с дневными свечами для исследовательской сверки.
- `knowledge_bot/match_scenario_charts.py` пробует восстановить привязку
  изображения по последовательности баров.
- `knowledge_bot/build_scenario_calibration_report.py` сравнивает сценарии,
  механические признаки и последующее движение.

На этом шаге эти программы **не запускались**: OCR, сетевые запросы, обучение
и брокер не запускались. Здесь уже подготовлен собственный локальный архив:
изображения лежат внутри его корня и подходят существующему импорту без
изменения кода. Команда для отдельного будущего запуска OCR из `botArtjahan`:

```powershell
.\.venv\Scripts\python.exe knowledge_bot/ingest_scenario_archive.py --out-root _knowledge_base/manual_reviews/scenarios_dzhahan_20260925 --no-gpu
```

Она читает `images` и создаёт OCR-индекс `scenario_index.jsonl`. Подготовленный
сейчас `pairs.md` не подменяет OCR-индекс и не заставляет импорт пропускать
непрочитанные изображения. OCR может потребовать дополнительных зависимостей
и загрузки моделей; текущая каталогизация их не требует.

Для просмотра и переноса достаточно этой папки целиком: ссылки `images/...`
разрешаются относительно манифеста и работают без Downloads. `source_root`
сохранён только как происхождение файлов. В `.gitignore` узко разрешены JPG
данной коллекции с именами `1D_N` и `1H_N`; остальные изображения проекта этим
изменением не открываются для Git. Коммит и отправка в GitHub не выполнялись.
