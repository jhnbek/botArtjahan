# Кнопка «вывести 31 уровень»

**Последующее изменение:** после разбора 20 удалений введена
[новая методика](../clean_reaction_selection_20260925/README.md). Снимок ниже
остаётся исходным набором для сравнения. Удаления из него теперь учитываются
также при новом обычном расчёте. После открытия архива кнопка
«Показать зеркальные и лимитные уровни» пересчитывает те же свечи по новым правилам.

Открывает все 31 зеркальный и лимитный уровень из общего отбора робота
на сохранённых свечах Bybit BTCUSDT 1d по 23 сентября 2026, 06:00 UTC.
Это тот набор, который обсуждался с пользователем, **до применения удалений
отдельных уровней**. Набор после удалений на тех же свечах содержит 24 таких
уровня и относится к другому результату.

Источник — `paranormal_body_1_6_20260925/historical/selection_report.json`,
метрика `general_selected_mirror_limit`. Все цены повторно получены через
`typed_review_levels` с рабочим отбором силы и расстояния 1,5%, без ограничения
количества и без привязки к ручным ценам. Использованы 549 закрытых дневных
свечей внутри окна 18 месяцев и 20 сохранённых исключений БСУ. Уровня 57 755,8
в наборе нет, уровень 58 042,6 есть.

`chart_snapshot.json` содержит свечи, полный набор уровней, БСУ, касания,
отдельные отметки ложных пробоев и происхождение расчёта с контрольными
суммами. Цены и состав набора зафиксированы для воспроизводимого просмотра.
Это не новый расчёт по текущим биржевым свечам. Порог тела паранормального бара
в расчёте — 1,6 ATR.

При нажатии кнопки не требуется интернет и предварительная загрузка графика.
Инструмент переключается на BTCUSDT 1d. Актуальные ручные линии накладываются
из журнала; текущие исключения БСУ скрывают соответствующие кружки.
Обычные кнопки редактирования и переключения режимов остаются доступны.

Для просмотра именно 31 исходной линии старые удаления отдельных уровней
из других режимов здесь не применяются. Они остаются в журнале и работают
в своих режимах. Новые удаления линий с причинами сохраняются с
`review_mode=working_31_review`, учитываются после повторного открытия и
отменяются кнопкой «Вернуть последний уровень». После удаления счётчик
покажет фактическое количество, например «30 из 31».

Проверки: воспроизведение всех 31 цены действующим алгоритмом; соответствие
каждого кружка/крестика цене и дате исходной свечи; загрузка без сети;
отображение ручных линий; удаление с комментарием, повторное открытие и возврат;
сохранность удалений из других режимов и доступность кнопок.
