# Алгоритм после последнего разбора 31 уровня

Исходная версия — та, которая дала **31 зеркальный/лимитный уровень**
на Bybit BTCUSDT 1d по 23.09.2026, 06:00 UTC. Поверх неё внесены исправления
по последним удалениям и комментариям пользователя. Предыдущий код сохранён
в `baseline_sources.json`, исходные свечи и 31 линия — в
`../working_31_review_20260925/chart_snapshot.json`.

Комментарии из предыдущего шага (20 удалений и новая ручная линия) сохранены
в [разборе](../working_31_feedback_20260925/README.md).
Журнал, старые расчёты, ручные линии и база `botArtjahan-main` не переписаны.

## Изменения общих правил

1. **Остановка или удержание перед отходом.** Одиночная свеча, открывшаяся
   около цены и продолжившая старое движение, не получает силу только за
   последующий большой отход. Проверяется приход к уровню, хвост отбоя либо
   серия близких удержанных касаний. Чистая серия допускает постепенный отход
   и не требует большого хвоста у каждого бара.
2. **ЛП не исчезает из траектории.** Его обратные движения учитываются при
   оценке эффективности. ЛП не даёт касаний или баллов; движение, созданное
   самим ЛП, вычитается из оцениваемого обычного отхода. Повторные отдельные ЛП
   прерывают связь старого касания с поздним движением. Один ЛП может сохранить
   прежнее основание — 58 042,6 остаётся, 57 755,8 не становится новым изломом.
3. **Распил проверяется возле формирования и среди взаимодействий с ценой.**
   Штраф не размывается месяцами свечей вдали от уровня. Новая чистая серия
   может восстановить основание. Изолированный двухбарный ЛП сам по себе
   не является жёстким запретом уровня.
4. **Канал проверяется по времени реакционных касаний, а не только БСУ.**
   Слабая внутренняя линия с единственным эпизодом уступает более сильным
   границам. Собственная чистая серия, подтверждённый излом или роль границы
   позволяют сохранить самостоятельный уровень. Обход кандидатов не влияет
   на результат сравнения силы.
5. **Последние ручные удаления применяются до отбора по расстоянию.**
   Обычный расчёт учитывает активные удаления из «кандидатов ±1%» и «31 уровня».
   Прежние удаления только типа «излом» сохраняют область действия. Возврат
   в исходном режиме отменяет соответствующее ограничение. Не удалённые
   линии не считаются автоматически подтверждёнными.

Сохранены правила выбора цены по плотным близким хвостам, повторяемости точной
цены, давности подходящего БСУ и усилению круглой ценой без произвольного
округления. Паранормальность — тело от **1,6 ATR**; ЛП только для входа;
отдельные уровни ГЭПа, проторговки и ЛП не добавляются. Дневное окно —
**18 месяцев**, минимальное расстояние — **1,5%**. Целевого числа уровней нет.
Цены и даты примеров не зашиты в общие правила; явные исключения берутся
из отдельного журнала пользователя.

## Параметры реализации

Это инженерные пороги для дальнейшей проверки, а не дословные численные
требования пользователя: приход от 0,5 ATR по последним трём барам; хвост
отбоя от 0,2 ATR; пара чистых касаний с промежутком до трёх баров; начало
отхода одиночной остановки на 0,5 ATR в течение трёх баров. Для чистой серии
последний быстрый порог не обязателен. Подтверждение обычного отхода остаётся
2 ATR за окно до десяти баров, либо 1,5 ATR для плотной лимитной группы или
подтверждённого круглого происхождения. Излом использует свой более широкий
анализ прихода. Штраф распила — четыре балла, умноженные на долю распильных
баров среди взаимодействий с ценой. Подтверждение пары не используется раньше,
чем известны оба касания, включая отложенное подтверждение недохода.

## Пересчёт на тех же свечах

| Расчёт зеркальных/лимитных уровней | Количество |
|---|---:|
| Исходная версия до последних поправок и удаления отдельных линий | 31 |
| Новые общие правила без списка удалённых целых уровней | 26 |
| Новые правила вместе с сохранёнными исключениями | 19 |
| Старый архив после 20 удалений вручную | 11 |

Общие правила сами исключили **11 из последних 20** удалённых цен.
Остальные **9** проходят правила по другим историческим эпизодам, поэтому
их убирают явные ограничения пользователя. В рабочем выводе этих 20 цен нет.
Это ещё не полное обобщение всех комментариев на другие рынки.

19 рабочих линий получены новым отбором: освобождённое место может занять
другой кандидат. Совпадение их количества с 19 ручными линиями не означает
совпадения всех цен. Все решения, причины и источники исключений есть
в [полном отчёте](historical/selection_report.md) и `historical/selection_report.json`.
Старые 18 приблизительных эталонов в машинном отчёте — отдельная историческая
метрика, а не оценка текущих 19 ручных линий.

## Просмотр и проверки

Перезапустить приложение → **«вывести 31 уровень»** →
**«Показать зеркальные и лимитные уровни»**. Второе нажатие пересчитывает
именно архивные свечи с прежней датой отсечения по текущему алгоритму,
с текущими исключениями. Сама кнопка «вывести 31 уровень» сохраняет старый
набор для сравнения. Прямое открытие обычного режима без архива использует
текущие биржевые свечи, поэтому количество может отличаться.

Полный запуск: **280 тестов пройдены**. Отдельно проверено настоящее
переключение Qt без сети: 11 оставшихся архивных линий → 19 пересчитанных,
19 ручных линий сохранены, исходные свечи совпали, журнал не изменён.
