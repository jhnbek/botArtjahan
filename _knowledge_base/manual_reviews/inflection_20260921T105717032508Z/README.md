## Для последующей доработки

- Проверить выбор бара-основания в примерах с замечанием о предыдущем баре.
- Разобрать случаи неверного отнесения другого типа уровня к излому.
- Проверить фильтрацию канала, распила и недостаточной реакции по отмеченным случаям.
- Сверить изменения с базой знаний и проверить каждый сохранённый пример.

Это задачи для ручного разбора, а не автоматически утверждённые изменения порогов. Числовые индексы БСУ относятся к загруженному тогда окну свечей; для дальнейшего сопоставления использовать также дату БСУ. Снимок свечей на момент каждого удаления журналом не сохранялся.
