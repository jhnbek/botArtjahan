# Подтверждение действующей методики

По просьбе пользователя сверены два блока: плавная шкала тела относительно
ATR и изменения из длительного разбора опорных баров (примеры 59 807,5,
62 846,8, 66 451,1, 67 679, 84 288, 93 538,4, 107 421,7, 112 577,7 и 123 742).
Указание длительности «26 минут 14 секунд» сопоставлено с этим разбором по
контексту переписки; время интерфейса не является идентификатором версии кода.

Проверка установила: перечисленные поправки уже реализованы и подключены
к обычному вычислению. Повторного изменения коэффициентов или двойного
начисления бонусов при этой фиксации не выполнялось.

## Что действует в алгоритме

| Правило | Изменение расчёта | Код |
|---|---|---|
| Плавная сила тела | `r = abs(Close-Open)/ATR14` по предыдущим свечам; вес `2.5*r/(r+1.5)` | `level_evidence_strength.progressive_body_strength` |
| Независимый вклад тела | Размер тела учитывается отдельно от прихода цены; два наибольших веса разных допустимых баров | `level_evidence_strength.body_strength_evidence` |
| Проверка самой БСУ | Слабая одиночная опора не заимствует основание у чужого отбоя; допустимы собственная реакция, плотная группа, подтверждённый излом или усиленный круглый исток | `level_evidence_strength.origin_evidence` |
| Плотность | Выборка близких хвостов с ограничением полного разброса; без объединения далёких краёв через цепочку промежуточных цен | `level_evidence_strength.dense_stopping_group` |
| Распил и остановка | Оцениваются приход/удержание у цены и история пересечений; дальние будущие свечи не разбавляют повреждение уровня | `level_selection.stopping_contexts`, `interaction_chopping` |
| ЛП прежней опоры | Хвост пробоя другой ранее возникшей границы не становится новой опорой или подтверждением соседней цены | `level_origin_context`, `level_structure` |
| Реакция после ЛП | Прирост от ЛП не даёт силы, обычное последующее движение оценивается отдельно; расчёт эффективности исправлен | `level_selection.ordinary_departures` |
| Самостоятельная смена БСУ | Новый независимо подтверждённый разворот может заменить опору; доказательство учитывается после подтверждающего закрытия | `level_origin_context.pending_reversal_origins` |
| Совпадение типов | Одна цена остаётся одним уровнем; +0,5 за каждый дополнительный подтверждённый тип, без повторов лимитных обозначений | `level_selection.level_type_confluence` |
| Расстояние | Из конфликтующих рабочих уровней в пределах 1,5% сохраняется более сильный | `level_selection.enforce_minimum_spacing` |

Паранормальность остаётся **телом от 1,6 ATR**. Бар с телом 1,35 ATR имеет
вес около 1,184 балла, но не получает название паранормального. Размер тела
сам по себе не отменяет проверки основания, касаний и реакции. Ложные пробои
остаются контекстом входа, без подтверждения, голосования за цену и бонуса силы.
Дневная история ограничена 18 месяцами. Коэффициенты шкалы и бонуса типов
являются явными настройками для ручной корректировки, не результатом обучения.

## Подключение к графикам

`desktop_app` вызывает `typed_review_levels` для зеркальных/лимитных и
паранормальных уровней, `inflection_review_levels` — для изломов. Оба пути
вызывают `discover_levels` с включённым `working_selection`, который применяет
проверку опор, шкалу тела и итоговый отбор по силе.

Для применения обновлённого кода необходимо перезапустить ранее открытое окно
робота и запустить обычный пересчёт. «Вывести 31 уровень» открывает сохранённый
исторический разбор; просмотр кандидатов ±1% намеренно показывает кандидатов
до итогового отбора. Эти режимы не подменяют обычный рабочий расчёт.

## Проверки и ограничения

Контрольные суммы кода и тестов совпадают с версией
[type_confluence_20260925](../type_confluence_20260925/active_methodology.json),
на которой успешно выполнены **322 теста**. Повторный полный прогон не требовался:
производственный код при этой проверке не менялся. Состояние подтверждения —
[verification.json](verification.json).

Последний воспроизводимый пересчёт BTCUSDT 1d по 23.09.2026 даёт 27 уникальных
уровней до исключения целых линий и 20 после сохранённых удалений. Обе цифры
учитывают 20 ранее удалённых БСУ. Это результат на сохранённых свечах, не
гарантия такого же количества на обновлённой истории.

Не все расхождения решены общими правилами: остаются вопрос выбора опоры
около 107 433, конкуренция 110 485,7 / 111 968 / 112 577,7 и допуск плотной
группы 85 211,1 через фильтр обычной реакции. Новая шкала уже убрала 84 288
из общего рабочего набора в пользу 83 560. Ручные исключения отражаются
отдельно и не выдаются за самостоятельное решение общего алгоритма.

Пользовательский журнал и справочная папка `botArtjahan-main` не менялись.
Самообучение и торговые операции не выполнялись.
