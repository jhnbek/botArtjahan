# Ручная разметка для корректировки алгоритма

Ручных уровней: 13; отклонённых: 54.

Типы и причины сохранены в calibration.json. comparison.json содержит результат проверки текущего алгоритма на candles.json. Допуск сопоставления цен — 0,1%, только для отчёта.

Пользователь подтвердил, что оставленные линии робота правильные. Точный набор просмотренных линий не сохранялся приложением; robot_levels.json — повторный расчёт на текущем кэше, а не доказательство состава открытого окна. Не сопоставленные линии не превращены в положительные метки автоматически.

Дальнейшие изменения нужно проверять как на удалённых уровнях, так и на явно добавленных изломах. Иные выбранные типы не означают запрет дополнительного типа. Автоматическое изменение порогов по этим отметкам не выполнялось.
