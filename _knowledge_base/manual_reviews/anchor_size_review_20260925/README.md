# Проверка опоры и силы остановленного движения

Пояснения пользователя от 25.09.2026 сохранены в [review.json](review.json).
Фактические OHLC, тела и ATR — в [facts.md](facts.md) и
[candle_checks.json](candle_checks.json). Исправлены общие правила в коде робота;
это ручная корректировка методики, без самообучения модели.

## Что изменено в вычислениях

1. **Качество самой БСУ.** Точная цена маленького одиночного бара больше не
   получает право стать опорой только за счёт реакции от другого касания.
   Нужны собственный обычный отбой, плотная группа, подтверждённый излом либо
   ранее реализованное основание круглого паранормального уровня.
   Все маленькие тела не запрещаются: чистая лимитная группа остаётся основанием.
2. **Плотность и остановленное движение.** К силе добавляются размер обычного
   бара и величина прихода к уровню в ATR для подтверждённых эпизодов отбоя,
   а также плотность близких цен. Используется компактная выборка хвостов,
   не среднее арифметическое всех касаний. Не допускается цепочка, в которой
   промежуточные близкие цены объединяют далёкие края. История распила учитывается
   при объединении контактов. Численные коэффициенты являются проверяемыми
   инженерными настройками, а не автоматически выученными закономерностями.
3. **ЛП относительно предыдущей опоры.** Бар может быть ложным пробоем прежнего
   уровня, даже если относительно собственного хвоста он выглядел касанием
   другой цены. Такой хвост исключается из опор, голосования за цену и силы.
   Предварительная опора защищается от подобных хвостов, но не объявляется
   подтверждённым изломом. Сохраняются цена прежней опоры и момент подтверждения
   события. Двухбарный ЛП появляется только после фактического возврата.
4. **Самостоятельная смена БСУ.** Если новый бар отдельно подтвердил разворот,
   а последующее закрытие прошло за прежнюю границу, допускается новая опора.
   Решение становится известно после подтверждения, а не на дату появления
   хвоста. Сохранены согласованные примеры 25 июня и 5 октября.
5. **Реакция после ЛП.** Положительное движение ЛП вычитается и из полезного
   отхода, и из пройденного пути. Обратное движение продолжает ухудшать
   эффективность. Уже подтверждённая чистая лимитная серия может пережить
   несколько ЛП, но силу ей даёт только последующий обычный отход. Для
   одиночной опоры мостик через несколько ЛП по-прежнему не допускается.

Порог паранормального **тела ≥1,6 ATR**, 18 месяцев дневной истории и минимальное
расстояние **1,5%** сохранены. Круглая цена усиливает обнаруженную структуру;
цена автоматически не подгоняется к ручной линии или круглому значению.

## Уточнения по данным

- В журнале уже заменена ручная линия 106 655,4495 на **107 433,7627** с комментарием
  о БСУ 29.08.2025. Её Low = **107 432,6**. Тело = **1,3467 ATR**, диапазон =
  **1,6797 ATR**: по действующему правилу тела этот бар не паранормальный.
  Ручная метка сохранена как мнение пользователя, автоматическая не подменена.
- Даты 04.02, 10.03 и 23.03.2026 из пояснения к 84 288 имеют близкие хвосты
  около **71 800**, не 85 211. Их новая привязка ожидает уточнения пользователя.
- Апрельские пересечения 84 288 действительно есть, но среди проверенных
  пересечений нет паранормальных тел по порогу 1,6 ATR. Частые пересечения
  остаются самостоятельным отрицательным признаком.

Журнал графика не переписывался; его состояние зафиксировано хешем отчёта.
Справочная папка `botArtjahan-main` не менялась. Старая кнопка «вывести 31 уровень»
по-прежнему открывает исторический снимок. Для нового вычисления нужно
перезапустить окно робота и использовать обычные кнопки типов уровней;
переход из снимка в обычный режим использует те же отображаемые свечи.
