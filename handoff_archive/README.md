# Исторические материалы рабочей папки

Здесь сохранены исходные `AUDIT.md` и `visuals/`, которые находились рядом
с папкой `botArtjahan` и раньше не входили в Git этого репозитория.
Файлы скопированы без изменения содержимого для продолжения работы на другом ПК.

HTML-демонстрация отражает раннюю версию алгоритма. Она не заменяет текущий
график и описание методики в `knowledge_bot/KNOWLEDGE_CONNECTION.md`.
Скрипт `visuals/build_inflection_demo.py` сохраняет старую привязку к структуре
родительской рабочей папки и предназначен для архива, не для запуска из этой папки.
