Каталог позволяет читать тексты и записи знаний прямо на GitHub.

зарегистрированные файлы — в `knowledge/blobs/`.
Исходные видео для работы с базой не нужны.

## Открыть базу на компьютере

Нужен **Python 3.12** с модулем `sqlite3` и FTS5.
Дополнительные Python-пакеты, API-ключи и установка через `pip` не требуются.
Клонируйте репозиторий или скачайте его ZIP; команды выполняются из его корня.

```powershell
python -m knowledge_core restore-published knowledge ../lecture-knowledge
python -m knowledge_core validate ../lecture-knowledge
python -m knowledge_core search ../lecture-knowledge "уровень" --limit 10
```

Команда восстановления проверяет контрольные суммы, распаковывает SQLite
и переносит все нужные файлы в новый каталог вне Git.
Существующий каталог назначения не перезаписывается.

Чтобы получить цитаты и связанные источники, передайте идентификатор из поиска:

```powershell
python -m knowledge_core show ../lecture-knowledge "<target_id>"
```

## Происхождение и качество

Это публичная переносимая редакция сохранённых результатов извлечения.
В служебных полях личные пути компьютера заменены относительными или
устойчивыми логическими ссылками. Тексты лекций, OCR, утверждения, правила
и содержательные решения сохранены; связи и контрольные суммы пересобраны
для публичной редакции. Ссылки `source-media/` обозначают исходные видео,
а `legacy-reference/` — старые файлы, не входящие в публикацию.

Редакции знаний имеют статус `imported_unverified`. Историческое одобрение
остаётся отдельной записью и не подтверждает достоверность автоматически.
Проверка целостности базы не заменяет проверку цитат, условий и противоречий.
Каталог создаётся из записей базы; новая интерпретация при его построении
не добавляется.

## Развитие и проверки

`knowledge_core/` содержит схему SQLite, импорт, поиск, прослеживание источников,
валидацию и перенос. В `knowledge_bot/` доступны подключение внешней базы знаний
и компоненты приложения, восстановленные из локальной истории Git.
Список восстановленных файлов и исходные коммиты указаны в `RESTORATION_FILES.txt`.
Окно запускается командой `.\.venv\Scripts\python.exe knowledge_bot/desktop_app.py`.

```powershell
python -m unittest discover -s tests -p "test_knowledge_core_*.py" -v
```

CI запускает синтетические тесты в Windows и Linux, а также восстанавливает
и проверяет опубликованный набор в Linux. Правила сообщения об уязвимостях
описаны в [SECURITY.md](SECURITY.md); условия использования — в [LICENSE](LICENSE).
