# Security policy

Do not disclose vulnerability details or exposed secrets in a public issue.
If the repository offers **Security > Report a vulnerability**, use that private
channel. Otherwise, open a minimal issue titled `Security contact requested`
without technical details; the maintainer will arrange a private channel.

Never include API keys, local data, transcripts, screenshots, logs, database
files, or other private artifacts in a report. Revoke an exposed credential
before reporting it.
