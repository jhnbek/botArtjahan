# MM\-068\-003

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Уровень нельзя сразу проводить по хвосту ложного пробоя без подтверждения\. Сначала уровень идет по основному бару, через который был ложный пробой; когда позже появляются бары, которые бьют в хвост ложного пробоя, уровень можно сместить по хвостам\. При этом нужно смотреть не маленький отрывок графика, а хотя бы около полугода истории, используя автомасштаб цены и времени\.

## Цитата

Пока не было подтверждения по хвосту, то мы не можем проводить уровень по хвосту\.\.\. после появления бара, который ударяет хвост ложного пробоя\.\.\. берем уровень по хвостам\.\.\. полгода это та информация

## Интерпретация

Черновое наблюдение из проверки пользовательских уровней; требует последующей сверки с базовыми уроками по уровням, ложному пробою, распилу и запасу хода\.
