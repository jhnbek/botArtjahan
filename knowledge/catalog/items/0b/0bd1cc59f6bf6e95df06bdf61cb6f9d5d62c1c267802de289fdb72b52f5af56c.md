# MM\-019\-002

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Для создания крипто\-списка в TradingView надо открыть Crypto Pair Screener, выбрать фильтры биржи и типа инструмента, затем искать пары через USDT\.

## Цитата

выбрать Crypto Pair Screener\.\.\. зайти в фильтры\.\.\. указать биржу\.\.\. выбираете Binance, потом выбираете тип символа Spot\.\.\. USDT написать

## Интерпретация

Список инструментов строится через фильтрацию, а не через ручной ввод каждой монеты\.
