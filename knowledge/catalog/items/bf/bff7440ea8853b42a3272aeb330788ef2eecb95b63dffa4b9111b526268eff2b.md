# MM\-006\-005

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Накопление вводится как ключевая будущая тема: нужно понять, зачем оно нужно, почему без него трудно создать движение и за счет кого происходит выход из накопления\.

## Цитата

Для чего накопление нужно\.\.\. почему не может быть без накопления\.\.\. как происходят выходы из накопления? То есть за счет кого происходит этот выход\.

## Интерпретация

Эта лекция дает вводную причинную модель накопления, но детали требуют поздних источников\.
