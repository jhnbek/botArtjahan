## Формулировка

Первое обязательное условие любой точки входа — наличие места для стоп\-лосса\. Если входить сразу после открытия дневного бара без локальной точки стопа, стоп за дневными барами обычно слишком большой для внутридневной сделки и может дать только 1R вместо 3R\.

## Цитата

наличие точки для стоп\-лосса

## Интерпретация

Фильтр входа должен блокировать сделку, если точка недействительности слишком далека для требуемого внутридневного R\.
