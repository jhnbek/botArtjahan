## Формулировка

Практика торговли домашки строится циклично: весь список гоняется по M5 каждый новый бар, потому что точка входа может появиться позже\. Один день не показатель; качество сценариев оценивается только на дистанции\.

## Цитата

листать весь список на M5 по кругу, каждый новый бар заново проверять\.\.\. один день не показатель

## Интерпретация

Помощник должен поддерживать повторный внутридневной скан, а не одноразовый список на открытии\.
