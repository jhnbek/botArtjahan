# MM\-014\-012

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Два ложных пробоя одного уровня в разное время не являются распилом, если между ними есть хотя бы один бар; распил начинается, когда проколы идут подряд\.

## Цитата

Когда между ложным пробоем и еще одним ложным пробоем есть хотя бы один бар, то это уже не распил уровня\.

## Интерпретация

Temporal separation distinguishes multiple false breakouts from immediate saw\.
