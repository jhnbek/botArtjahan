# MM\-003\-005

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Силу уровня можно уточнять на 1H/4H: на дневке уровень может выглядеть как прошитый насквозь, но внутри дня могут быть четкие касания/подтверждения, которые делают уровень актуальным\.

## Цитата

На часовом таймфрейме есть подтверждение уровня\.\.\. чем больше касаний в уровень, тем сильнее уровень\.

## Интерпретация

Проверка уровня должна иметь multi\-timeframe step: D для уровня, 1H/4H для качества подтверждений\.
