# MM\-009\-017

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Для сложного ложного пробоя используется stop\-market order ниже уровня, чтобы short сработал только при возврате цены обратно в short zone; чем больше баров стоят над уровнем без продолжения, тем сильнее ожидаемый возврат\.

## Цитата

Мы можем выставить по 4\.99 short, stop market order\.\.\. чем больше количество баров наверху, тем сильнее будет возврат\.

## Интерпретация

Исполнение должно быть условным, а не market\-entry до подтверждения возврата в нужную зону\.
