# MM\-006\-008

[Каталог](../../README.md)

Материал импортирован. Статус `imported_unverified` не подтверждает содержательную достоверность.

Статус: imported\_unverified

## Формулировка

Лимитный игрок может скрывать реальный размер позиции, показывая в стакане только часть объема и обновляя заявку по мере исполнения; это похоже на iceberg liquidity\.

## Цитата

Он может не показывать полностью весь объем\.\.\. Как только разобрали 200 тысяч\.\.\. он может выставить вторые 200 тысяч\.\.\. если лимит хочет скрыть свой объем, это называется айсберг\.

## Интерпретация

Детекторы не должны считать visible order book quantity полной ликвидностью уровня\.
